Bloquea usuarios por email o ID, impide login normal y WooCommerce, y redirige a la home.

== Description ==
Plugin independiente derivado del módulo de bloqueo de usuarios de YGB Escudo 2. Permite bloquear indefinidamente cuentas, con persistencia del email aunque la cuenta sea eliminada. Incluye mensajes personalizados globales o por usuario.
